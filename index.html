A system that builds systems

Sistem kuran bir sistem

A cross-project agent system on Claude Code. Every project gets its own squad of subagents, a knowledge vault holds each project's state, and a gate stops a new product from starting before the current one ships.

Claude Code üzerinde, projeler arası çalışan bir ajan sistemi. Her projenin kendi alt-ajan ekibi var, her projenin durumu bir bilgi kasasında tutuluyor ve bir kapı, mevcut ürün yayınlanmadan yenisinin başlamasını engelliyor.

  • Agents never message each other: each one starts cold, and the system stays in sync through shared files and deterministic checks.
  • Ajanlar birbirine mesaj atmaz: her biri sıfırdan başlar; sistem ortak dosyalar ve deterministik kontrollerle senkron kalır.
  • Core agents in every project: a critic that defaults to "refuted", and a user proxy that walks the product as a stranger.
  • Her projede çekirdek ajanlar: varsayılanı "çürütüldü" olan bir eleştirmen ve ürünü yabancı bir kullanıcı gibi gezen bir temsilci.
  • System agents that check every path and cross-reference still resolves, and run the hook scripts against adversarial inputs.
  • Her yolun ve çapraz referansın hâlâ çözüldüğünü denetleyen, hook betiklerini kötü niyetli girdilerle çalıştıran sistem ajanları.
  • PowerShell hooks: a session brief at start-up and a secret sentinel before tool use. Runtime config is mirrored into the vault and restorable.
  • PowerShell hook'ları: açılışta oturum özeti ve araç kullanımından önce gizli-bilgi nöbetçisi. Çalışma ayarları kasaya yansıtılır ve geri yüklenebilir.

ReversalEA

MetaTrader 5 Expert Advisor · MQL5 · XAUUSD
MetaTrader 5 Expert Advisor · MQL5 · XAUUSD

A trading bot I treat as a measurement exercise. One position at a time, fixed USD profit target and loss limit, direction flips after a loss.

Bir ölçüm egzersizi olarak ele aldığım bir trade botu. Aynı anda tek pozisyon, sabit USD kâr hedefi ve zarar limiti, zarardan sonra yön değiştirir.

  • Trade-history analysis: 94.5% of one week's loss came from server hours 22–02 → hour and spread gates added.
  • Found and fixed a 10× unit error that made the backstop stop-loss ten times wider than designed.
  • Backtest on real ticks and a 49-combination optimisation, run through MT5's MCP server. 0 of 49 profitable out of sample.
  • Two-host setup: a 24/7 trading host and a read-only analysis host. The AI never calls trade tools.
  • İşlem geçmişi analizi: bir haftalık zararın %94,5'i sunucu saati 22–02 arasından geldi → saat ve spread kapıları eklendi.
  • Yedek stop-loss'u tasarlanandan on kat geniş yapan 10× birim hatası bulundu ve düzeltildi.
  • Gerçek tick verisiyle backtest ve 49 kombinasyonlu optimizasyon, MT5'in MCP sunucusu üzerinden. Örneklem dışında 49'dan 0'ı kârlı.
  • İki makineli kurulum: 7/24 işlem makinesi ve salt-okunur analiz makinesi. Yapay zekâ işlem araçlarını asla çağırmaz.

How I workNasıl çalışırım

Agents do the building. Evidence decides.

İnşayı ajanlar yapar. Kararı kanıt verir.

Scope a squad

Ekibi tanımla

3–5 agents per project, each with one job: builders, read-only critics, a shipper for non-code work.

Proje başına 3–5 ajan, her birinin tek işi var: inşa edenler, salt-okunur eleştirmenler, kod dışı iş için bir yayıncı.

Build

İnşa et

Agents write and run code through Claude Code, connected to real tools over MCP (Roblox Studio, MetaTrader 5).

Ajanlar Claude Code ile kod yazar ve çalıştırır; MCP üzerinden gerçek araçlara bağlıdır (Roblox Studio, MetaTrader 5).

Attack the claim

İddiaya saldır

A critic that starts cold checks every "done" with file-and-line evidence and defaults to refuted.

Sıfırdan başlayan bir eleştirmen her "bitti"yi dosya-satır kanıtıyla kontrol eder; varsayılanı çürütmektir.

Write it down
